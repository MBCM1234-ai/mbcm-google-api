Privacy policy

MBCM Google API. Effective November 18, 2026.

MBCM Google API is an internal reporting tool that the search team at Colle McVoy operates. Only approved Colle McVoy employees can sign in. This policy explains what Google user data the tool accesses and what happens to it.

Data the tool accesses

When an employee signs in with a Google account, the tool can read data from the accounts that employee already manages:

  • Google Ads: account and campaign structure, budgets, spend, and performance.
  • Google Analytics: reports and property settings.
  • Google Search Console: search performance, sitemaps, and URL inspection results.
  • Google Tag Manager: container, tag, and version settings.

The Google Analytics, Search Console, and Tag Manager permissions are read-only. Google Ads offers a single permission that also allows changes, so the tool turns off every feature that could change a Google Ads account.

How the tool uses the data

The search team uses the data to build reports, check budget pacing, and review account setup for Colle McVoy clients. The tool does not use the data for advertising, and Colle McVoy does not sell it.

Where the data is stored

The tool runs on the employee's work computer. The sign-in token stays in a file on that computer and is not uploaded anywhere. Data the tool retrieves is saved on the same computer only when a report needs it.

Who the data is shared with

The tool works inside Claude Code, an AI assistant made by Anthropic. When an employee asks a question, the tool sends the data needed to answer it to Anthropic for processing. Colle McVoy does not share the data with any other third party.

No Google user data is used to develop, improve, or train generalized artificial intelligence or machine learning models.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

An employee can remove the tool's access at any time at myaccount.google.com/permissions. Removing access makes the stored sign-in token stop working. Colle McVoy deletes the token file and any saved report data on request.

Changes to this policy

Colle McVoy updates this page when the tool changes how it handles data. The effective date at the top shows the latest version.
