MBCM Google API

MBCM Google API is an internal reporting tool that the search team at Colle McVoy uses. It is not a public product, and only approved Colle McVoy employees can sign in.

What the tool does

The tool reads data from Google Ads, Google Analytics, Google Search Console, and Google Tag Manager for accounts the signed-in employee already manages. The team uses that data to build reports, check budget pacing, and review account setup for Colle McVoy clients.

The tool runs on the employee's work computer. It does not change campaigns, tags, or settings in any Google account.

Why the tool asks for Google account access

  • Google Ads: read campaign structure, spend, and performance.
  • Google Analytics: read reports and property settings.
  • Google Search Console: read search performance, sitemaps, and URL inspection results.
  • Google Tag Manager: read container, tag, and version settings.
